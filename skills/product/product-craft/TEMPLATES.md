# Product Craft Templates

repository's existing product vocabulary and decision format.

## Outcome Roadmap

```markdown
# Outcome Roadmap

| Horizon | Outcome or Decision | Evidence and Confidence | Expected Value | Investment Boundary | Owner | Review or Revisit Trigger |
|---|---|---|---|---|---|---|
| Now | | | | | | |
| Next | | | | | | |
| Later | | | | | | |
| Never | | | | | | |
```

Keep Later coarse. For Never, record why the product will not invest under the
current conditions and what new evidence would justify reconsideration. Do not
derive dates from a horizon.
