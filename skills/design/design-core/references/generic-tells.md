# Generic-Look Tells

Review gate for any visual artifact (page, screen, deck, dashboard). It is an
owner position (aesthetic), not a measured harm: the tells say nothing
specific about the product, which is the defect. Detail failures that often
accompany them, weak hierarchy, grouping, contrast, and spacing, are
supported [SRC-WEB-031].

## How to run it

1. Write the concept sentence and three to five constraints first.
2. Walk the list below against the artifact. Each hit is a finding: fix it
   or record in one line why this product needs it.
3. Ask what only this product could look like. If nobody can name it, the
   direction is not done, whatever the list says.

## Tells

- Inter or a system font only, with no display voice.
- A purple-blue or violet-indigo decorative gradient.
- A centered hero plus three equal feature cards.
- One radius, padding, and card height everywhere.
- A colored left-edge accent bar on rounded panels.
- Glassmorphism without a reason (depth or layering the task needs).
- Emoji or generic line icons as feature bullets.
- Stock 3D or blob illustrations instead of the product itself.
- Fade-in-on-scroll on everything.
- Everything visible at once, with no hierarchy of attention.
- Only the happy path: no empty, loading, error, or no-permission states.
- Placeholder names (Acme, Jane Doe) and invented round numbers.
- Slogan copy that fits any product.
- Unthemed component-library defaults: type, radius scale, color semantics,
  and motion left as shipped.

## Not a tell

A tell is a default taken without a decision. Any item above is fine when the
concept calls for it and a constraint says so.
