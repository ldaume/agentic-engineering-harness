# Contributing

This repository is published for consumption. Install or pin Skills, scaffold a
harness in your own repositories, and adapt methods under your authority.

Do not treat stewardship in a consumer harness as a duty to open pull requests
or push changes here. Agents working in third-party repositories must not write
back to this upstream.

I maintain this catalog. External contribution pull requests are not the
supported integration path. Security reports use
[`SECURITY.md`](./SECURITY.md) private vulnerability reporting only.
